# team_loop

Автономный цикл выполнения задач для движка Strata: **Аналитик → Исполнитель ↔
Изолированный Ревьюер**, с защитой от переполнения контекста через `handoff.md`.
План работ — в [PLAN.md](PLAN.md); здесь реализован **ШАГ 1**.

## ШАГ 1 — `team_config.py`

Конфигурация и утилиты подсчёта токенов: загрузка `.env` с дефолтами, пороги
Handoff, `extract_used_tokens()`, `is_context_critical()`.

```powershell
python team_config.py
```

Модуль импортируется без ошибок и печатает текущие лимиты токенов — это и есть
критерий готовности Шага 1.

## Настройка

Скопируйте `.env.example` в `.env` (`.env` в `.gitignore`) либо задайте
переменные окружения — уже установленные переменные окружения важнее файла.

| Переменная | Дефолт | Смысл |
| --- | --- | --- |
| `OPENAI_BASE_URL` | `http://localhost:1234/v1` | адрес локального OpenAI-совместимого сервера |
| `OPENAI_API_KEY` | `EMPTY` | ключ этого сервера |
| `MODEL_NAME` | `qwen-local` | имя модели |
| `MAX_CONTEXT_TOKENS` | `32768` | полный размер контекстного окна |
| `HANDOFF_FREE_RATIO` | `0.25` | долю контекста нужно оставить свободной |
| `HANDOFF_TOKEN_LIMIT` | `MAX_CONTEXT_TOKENS * (1 - RATIO)` | порог Handoff, зажимается в диапазон `1..MAX_CONTEXT_TOKENS` |
| `MAX_STEP_ATTEMPTS` | `3` | попыток исправить один шаг плана |
| `TOKEN_ESTIMATE_DIVISOR` | `3` | делитель запасной оценки `len(text) // N`, когда сервер не вернул `usage`; для кириллического контекста реалистичнее `2` |
| `HANDOFF_FILE`, `HANDOFF_BACKUP` | `handoff.md`, `handoff.bak` | файлы состояния механизма Handoff |

Некорректное значение не роняет импорт модуля: в `stderr` пишется
предупреждение, значение заменяется дефолтом.

## Кодировки и пути (важно для Windows)

* `.env` читается как UTF-8 (с BOM и без) и как UTF-16 с BOM — именно его
  даёт `echo "K=v" > .env` в Windows PowerShell 5.1. Файл в другой кодировке
  (например, CP1251) не угадывается: предупреждение в `stderr` и дефолты.
* `.env` ищется сначала в текущем каталоге, затем в каталоге модуля.
  Python-dotenv, если он установлен, получает уже прочитанный модулем текст,
  а не путь, — поэтому результат не зависит от наличия этой необязательной
  зависимости.
* `stdout` и `stderr` переводятся в UTF-8 при импорте модуля, чтобы
  предупреждение с кириллицей не упало `UnicodeEncodeError` в перенаправленный
  лог (`python team_config.py > log.txt 2>&1`).
* Относительные `HANDOFF_FILE` и `HANDOFF_BACKUP` отсчитываются от каталога
  модуля, а не от текущего каталога процесса: `--resume` найдёт `handoff.md`,
  из какого бы каталога его ни запустили.
