# Исправления по ревью

## Исправлено

- В `isolated_reviewer.py` сохранён приоритет точных сообщений о синтаксических ошибках, сбое окружения и отсутствующих переданных файлах; отсутствие путей проверяется после этих веток.
- `handoff.bak` больше не подхватывается обычным запуском. Для явного восстановления добавлен `--resume`; при неудаче планирования резервный файл остаётся нетронутым.
- Лимит `write_file` задан независимо как 200 000 символов. Дополнительно он учитывает приближённый свободный запас до порога Handoff на каждый запрос, с защитой для нескольких записей в ответе.
- При достижении порога после ответа модели цикл не исполняет новые вызовы инструментов. Перед созданием handoff проверяются уже записанные артефакты, а в handoff передаются их пути и объективный результат.
- Обновлена документация README.

## Проверка и ограничения

Полный регрессионный запуск не выполнялся по явному ограничению пользователя. Перед отправкой проверены diff, соответствие импортов и вызовов между модулями, Windows-пути через `pathlib.Path`, обработка ошибок и отсутствие тестовых запусков. `git diff --check` пройден.
